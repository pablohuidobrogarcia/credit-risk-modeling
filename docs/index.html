What did not work, and limitations

Findings about discrimination, LGD, calibration and the forecast are reported next to their tables above.

  • Antithetic variates give a negligible variance reduction (reported, not hidden).
  • No macroeconomic variables; the data ends in 2018, so only one credit cycle is observed.
  • Reject inference is exploratory only and feeds no headline number. The data contains approved loans only, so the selection bias cannot be corrected.
  • Clustering is weakly separated: silhouette 0.1840, stability ARI 0.9566, and k-means separates the default rate by only 0.54 pp.

Data source

Lending Club public loan-level snapshot (2007–2018), resolved loans only. The dashboard is descriptive: it does not estimate a causal effect of any segment.

How the rates are computed

Observed default rate = defaults ÷ loans in the segment. The selection summary shows a Wilson 95% confidence interval. Predicted PD is the mean calibrated champion prediction for the segment; expected loss uses the EAD-weighted PD × the effective portfolio LGD, reconciled to the headline EL rate.

Small-n masking

—

Limitations

    Segments are correlated with grade and term, so the differences are descriptive, not causal. Small segments carry wide intervals and are masked in the map.
