| id | term | one-line summary |

| `grade` | Lender grade | The A-to-G risk grade assigned by the original lender, not by this project's model. |
| `dti` | Debt-to-income ratio (DTI) | Monthly debt payments divided by monthly income. |

| `term` | Term | The scheduled length of the loan, usually 36 or 60 months. |
| `vintage` | Vintage | The year in which the loans were originated. |
| `pd` | Probability of default (PD) | The estimated chance that a loan will default. |
| `lgd` | Loss given default (LGD) | The share of exposure lost when a loan defaults, after recoveries. |
| `ead` | Exposure at default (EAD) | The amount outstanding when a loan defaults. |
| `el` | Expected loss (EL) | The average credit loss implied by PD, LGD and EAD. |
| `ul` | Unexpected loss (UL) | The variation of losses around expected loss, usually measured as a standard deviation. |
| `approval-rate` | Approval rate | The share of applicants accepted at a chosen cutoff. |
| `bad-rate` | Bad rate | The default rate among a group, often among approved loans. |
| `cutoff` | Cutoff | The score threshold at or above which an application is approved. |
| `percentile` | Percentile | The share of a distribution at or below a value. |
| `scorecard` | Scorecard | A transparent points system built from a logistic regression on binned features. |
| `score` | Score and points | A score is a fixed base plus the points for each selected bin. |
| `points` | Points | The contribution of one scorecard bin to the total score. |
| `pdo` | Base score, base odds and PDO | Scaling constants that map log-odds to a points score: base score, base odds and points to double the odds. |
| `woe` | Weight of evidence (WoE) | A bin-level transform that compares the share of goods and bads in a bin. |
| `iv` | Information value (IV) | A summary of how much a variable separates goods from bads across its bins. |
| `logistic-regression` | Logistic regression | A model that maps inputs to the log-odds of a binary outcome. |
| `lightgbm` | LightGBM / gradient boosting | An ensemble of shallow decision trees fitted sequentially to reduce error. |
| `champion` | Champion vs challenger | The champion is the selected model; challengers are alternative models compared on the same out-of-time window. |
| `features` | Features | Input variables known at origination, such as income, DTI and utilization. |
| `leakage` | Data leakage | Using information that would not be available at the moment a decision is made. |
| `calibration` | Calibration | How closely predicted probabilities match observed frequencies. |
| `brier` | Brier score | The mean squared error of predicted probabilities against binary outcomes. |
